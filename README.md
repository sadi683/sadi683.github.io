## 🐙 How to Upload to GitHub & Deploy Live

### Method 1: Upload via GitHub Web Interface (Drag & Drop)
1. Go to **[https://github.com/new](https://github.com/new)** and create a new repository (e.g. `rasooi-tiffin-service`).
2. Keep it **Public** (or Private). Do not initialize with a README (as we already have a full one).
3. On the setup page, click the link: **"uploading an existing file"**.
4. Drag and drop all files from the extracted `rasooi-tiffin-github` folder (or select `index.html`, `server.py`, `orders.json`, `netlify.toml`, `Procfile`, `.gitignore`, `README.md`, `css/`, `js/`, and `netlify/`).
5. Type a commit message (e.g. `Initial release: Rasooi Tiffin Service`) and click **Commit changes**.

### Method 2: Push via Git CLI / Terminal
If you have Git installed:
```bash
git init
git add .
git commit -m "Initial commit: Rasooi Fooding Made Easy"
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```

## 🌐 Free 1-Click Hosting Options

### 1. GitHub Pages (Free Instant Website)
1. In your GitHub repository, go to **Settings** > **Pages**.
2. Under **Build and deployment** > **Branch**, select `main` branch and root `/ (root)` folder.
3. Click **Save**.
4. In ~60 seconds, your site will be live at `https://<YOUR-USERNAME>.github.io/<REPO-NAME>/`!

### 2. Netlify Deployment
This repository is pre-configured with `netlify.toml` and `@netlify/edge-functions`.
1. Go to [https://app.netlify.com/start](https://app.netlify.com/start).
2. Connect your GitHub repository.
3. Publish directory: `.` (root).
4. Netlify will automatically activate Edge Functions for `/api/*` and host the website with zero configuration.
